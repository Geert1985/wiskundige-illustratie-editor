# T4 contract

Version 1.0.0, 2026-10-12. Explicit user authorization: execute T4. Branch chatgpt/editor-development; no T5 implementation.

- Keep v7 and textSchema 1/2/3. Optional textContent.width is a positive width in SVG/CSS pixels, independent of geometry zoom like font size; null keeps automatic width. Format grant controls width. No implicit legacy migration.
- Shared mixed layout wraps ordinary text at whitespace and long words at Unicode grapheme boundaries. Formula and dynamic-value atoms remain indivisible; an atom wider than the requested width overflows visibly rather than being clipped or corrupted. Preserve paragraph alignment, hard breaks, scripts, marks, baseline, anchor and rotation. Legacy rich text without fixed width retains its compatibility path.
- Width edits participate in local editor history and one outer text.commit; Cancel is private. Canvas and standalone export use the same resolved layout. Bounds follow displayed glyphs without moving the object anchor.
- SVG/PNG export prepares local math/font assets, uses the current authorized engine snapshot and rejects changed document/revision/permission epoch/view or disposed editor before delivery. PNG is derived from permitted SVG export and requires the same document.exportSVG grant; no new permission bypass or document mutation.
- PNG text uses native SVG positions and loaded local fonts, rasterized as private in-place bitmaps before geometry rastering. Quote numeric font family names in editor/SVG CSS. Native-font PNG avoids dependence on Image webfont loading and retains layer order/transforms/parent opacity; public SVG stays editable font-embedded text. No persisted images or new font library.
- Raster limits: positive integer dimensions, maximum side 8192 pixels and 16777216 pixels total; scale >0 and <=4. Decode timeout and null/error toBlob fail explicitly. Release Blob URLs and hidden native-SVG host on success/error. Per-export text bitmap budget is also 16777216 pixels and 65536 graphemes; over-budget or non-lossless text indexing fails explicitly. No external fonts, foreignObject or unsanitized math output.
- Validate Node wrapping/Unicode/atoms/anchor/permissions/roundtrip and export limits/stale/error cleanup. Edge: width UI/local history/Cancel, mixed values/formulas, actual SVG and PNG downloads, offline decoding, snapshot denial, restricted output, keyboard/focus/Escape/fullscreen, responsive screenshots and measured load/layout performance. Full Node/Edge regressions.
- Real OS IME, screen reader, external clipboard/viewers and physical-device visual acceptance remain NOT EXECUTED unless actually performed. No claim of full accessibility approval from automated DOM tests.
