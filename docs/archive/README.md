# WIE — Archief van historische documentatie

Dit archief bewaart eerdere implementatie-, verificatie- en acceptatiebewijzen. De rapporten zijn **historisch**: huidige functionaliteit en normatieve regels volgen uit de vrijgegeven code, de actuele contracten en [de ontwikkelroadmap](../DEVELOPMENT-ROADMAP.md).
