# Point coordinate projections contract

2026-10-10. Specification 1.4.0 section 9 fetched from main f166078; additive implementation on existing development branch. Optional point-only coordinateProjections={schema:1,frame:"cartesian",mode:"none"|"x"|"y"|"both",showValues:boolean}. Absence = off, no legacy migration or emitted default property. Strict type/version/frame/unknown-key validation, atomic import/update; no geometric object, construction recipe or dependency added.

Active frame is explicitly the document Cartesian axes, currently the only supported frame. Unsupported future frames are rejected, not reinterpreted. Vertical x projection from (x,y) to (x,0); horizontal y projection to (0,y). Corresponding visible axes required (global showAxes and per-axis flag). Helpers inherit point color, opacity and bounded stroke width, with dotted fixed screen-pixel pattern. Hidden/invalid/layer-hidden/unreadable points produce no helpers. Locks preserve displayed helpers and prevent edits. Course/assessment use existing propertyFields grants for coordinateProjections; default denied, author can publish/show/export without new tool/source permissions.

Lines clipped to the same actual viewport bounds used for drawing; labels only when the axis foot is visible, clamped inside viewport. Suppress zero-length lines at axes/origin but retain requested zero values. Value labels on opposite side to regular tick labels, prefixed x = or y =; identical axis/value labels deduplicated within a render. Signed values share units/scale/precision formatting, including normalized negative rounded zero; absent units retain legacy notation. Axis ticks remain coordinate values.

Presentation is inside the point SVG group, pointer-events none, no selectable label attributes or snap anchors. Real point geometry remains sole hit/snap/rectangle-select target. Parent/parameter changes, move previews, undo, cancellation, source invalidity/recovery, pan, zoom and fullscreen all reuse existing render/transform/graph owners. JSON persists optional settings; SVG includes helpers without editor handles and uses export viewport. PNG rasterization of that SVG includes the same helpers (no new standalone PNG-export UI introduced). Settings use object.setProperties, one undo step and existing semantic replay; duplicate/detach preserve them, deletion removes them with the point.
