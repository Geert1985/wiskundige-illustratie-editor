# Dynamic angles and angle units contract

2026-10-10, specification 1.5.0 section 10 explicitly authorized. Three schema-2 recipes anglePoints(point,vertex,point), angleDirections(line,line), angleXAxis(line), result angle. Direction = stored start-to-end (including straight lines, polygon edges). Normalize nonzero vectors; atan2(det,dot), smallest abs signed angle in [0,180], directed counterclockwise first-to-second in [0,360). Three points retain their vertex; two directions use support-line intersection, disregarding finite domains, or first start for parallel/antiparallel directions. X-axis reference uses positive Cartesian x at line start. Explicit Cartesian document frame; future frames rejected. Collapsed arms/directions <=1e-9 recoverably invalid; zero/parallel angle 0 and antiparallel 180 valid. Coordinate bounds and graph/cascade/identity policies remain authoritative.

Optional angle-only angleSettings={schema:1,frame:"cartesian",mode:"smallest"|"directed",unit:"document"|"deg"|"rad",precision:null|integer0..10,showArc:boolean}. New linked angles receive defaults, explicit static tools retained. Cached vertices are computed geometry, immutable while linked; settings, style and label offsets preserved. No ghost full-length arms for linked measurements. Fixed screen-size arc; directed reflex arc and label sector agree; zero angle suppresses collapsed arc. showArc independent of label; free measurement text untouched.

Optional meta.angleMeasurement={schema:1,unit:"deg"|"rad",precision:integer0..10}; author-only document.setAngleMeasurement command, history and replay. Absent metadata retains old degree formatter and existing document measurement precision. Explicit default/override use fixed decimal comma; radians = degrees*pi/180, no physical length scale. Overrides may use document unit/precision independently. Units changes never alter geometry or graph. New document default degrees/two decimals; old documents not migrated.

Meten angle split menu adds three linked choices with step instructions, source hover, remembered choice and fullscreen tool menu. Default fresh angle group uses linked points; explicit Hoek (statisch) and Rechte hoek retained. Inspector controls mode, unit, precision and arc, also when invalid/locked; locked settings disabled. Existing propertyFields grants control angleSettings; sourceTools/allowedTools required per recipe in course/assessment, geometry edits denied. Document defaults readonly in restricted profiles, metadata projected/exported. JSON, SVG/PNG, detach/cascade, duplicates, groups/layers and semantic replay reuse existing owners. Hidden or invalid measurements omitted and restored after recovery. No broader dynamic-length or dynamic-text feature introduced.
