# T3 implementation contract

Version 1.0.0, 2026-10-12. Explicit user authorization: “T3 mag je starten”. Work only on chatgpt/editor-development; T4 is not authorized. This contract refines architecture sections 12/16 without activating T5 expressions.

- v7/textSchema 3 adds `{id,kind:dynamicValue,binding:{sourceId,property},format:{precision,unitMode,angleMode,prefix,suffix},marks}`. No cached result, source name, HTML or editor JSON. Properties reuse existing DynamicText applicability; no diameter/vector-component inference. A coordinate pair is two fields plus punctuation.
- unitMode: document, none (hide suffix, retain document scale), u, dimensionless, mm/cm/m/km. Physical conversions reuse MeasurementUnits once; incompatible physical/abstract changes produce unavailable. angleMode: document (including existing source overrides), deg or rad. Precision null or 0–10. Formula source remains independent of value bindings. No evaluator.
- Author retains missing IDs for undo/import recovery and may read hidden/locked sources. Restricted fields require effective read+display including layer availability, and property in textSourceProperties. Denied/missing restricted atoms project to plain “niet beschikbaar”, without ID/property/format/name/value leaks. No persistent value cache. Existing legacy binding policy remains unchanged.
- text.commit requires content+references for inserting/removing/rebinding fields; format for format/marks changes. Kept active references are revalidated on every commit. New-object/duplicate grants and retained-source rights are checked separately. Moving an unchanged marked atom only needs content. Revision/epoch conflicts cannot commit stale drafts.
- Legacy migration is explicit (`text.commit` with migrateLegacy:true): validated private prefix/value/suffix draft, inherited supported font/color/anchor, stable object position/rotation/organization, server-owned legacyStaticText backup, no simultaneous textBinding. Cancel makes no mutation; OK is one history action. Unsupported legacy typography is refused rather than silently replaced. Explicit text.restoreStatic restores the original static backup; restricted output omits that backup. Duplicating inline fields remaps only sources actually copied; legacy bindings stay on the old path.
- An ephemeral reverse source→object/fragment index is exposed for dependency discovery. Values are resolved against current snapshots at render, including source updates, units, delete/undo and policy revocation. Layout/export do not move object anchors.
- Limits: 128 fields/text, 512/document and 4096 codepoints per resolved value, in addition to existing rich-text/command/replay quotas. Schema 4/future calculated fields remain denied. Unknown fields and malformed bindings fail atomically. Old opaque legacyStaticText extensions remain inert until schema 3; upgrade collisions are explicitly refused.
- Required evidence: Node schema/values/migration/rights/redaction/remapping/history/replay/limits and full existing regression; Edge multi-source editing, live geometry/units, delete/undo, fullscreen, local atom editing, cancel/conflicts, JSON/save/reload and offline mixed SVG→PNG. Real IME/AT/manual external-viewer checks remain explicitly not executed unless performed.
